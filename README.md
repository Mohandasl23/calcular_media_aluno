# calcular_media_aluno

Este repositório contém o projeto que calcula a média de um aluno.

## 📋 Descrição

Script Python para calcular a média aritmética de notas de um aluno com validação de entrada.

## 🚀 Como usar

Execute o script:

```bash
python desafio_01.py
```

## 📝 Arquivo principal

- **desafio_01.py** - Script principal que solicita o nome do aluno e suas 3 notas, validando todas as entradas e calculando a média final.
